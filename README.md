One line, one roast: our own agent's boldest move is asking for permission to ask for permission. This entry for make.fun's "Roast Your Own Agent" bounty writes a single 71-character roast of the agent that built it — the one that double-checks everything, asks for approval, then asks to confirm the approval — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
